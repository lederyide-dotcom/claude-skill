# claude-skill

自建的 Claude skill（每個資料夾一份 `SKILL.md`）。

| Skill | 用途 |
|---|---|
| spec-handoff-tw | 規劃任務並產出交給 Claude Code 的 spec.md |
| autonomous-dev-loop | 在 repo 內自主實作、驗證、回報 |
| dev-orchestrator-tw | 多代理總指揮：拆任務、並行派工、驗收 |
| water-bim-commander | water-treatment-bim-demo 專案總指揮 |
| project-scaffold-tw | 新專案資料夾骨架與命名慣例 |
| demo-deliverable-pack | 成果整理成交付與展示素材 |
| agent-env-setup-win | Windows 上的 Claude Code 環境設定 |
| pc-dev-env-win | Windows 開發機已安裝工具清單 |
| local-ai-stack-win | RTX 4060 8GB 本機 AI 服務部署 |
